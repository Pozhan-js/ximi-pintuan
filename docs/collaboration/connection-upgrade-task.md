# 前置任务 0：升级连接工具

个人实战项目有独立的系统前置任务，排在原作业前。它不依赖老师发布模板策略，也不新增或改写课程作业合同、任务编号、验收条件、审核、交付与完成记录。已开始和已完成作业仍可查看；开发、领取与提交须先通过当前设备的升级要求。

Codex、Cursor、Claude Code、GLM 及其他 AI Agent 均可使用，不设置品牌白名单。本任务升级的是仓库里的课程连接工具，既不要求更换当前 AI 产品，也不要求其支持 Codex Hook 或 `/hooks`。

网页提供“复制升级指令给 AI 工具”，原工具的任务读取也会收到响应中的 blockingPrerequisite。服务端拒绝未完成的开发请求并指出升级入口；不会凭页面的一次按钮点击放行。网站不能主动向所有正在运行的 AI 会话插入消息，下一次网页访问、任务读取或交付检查才会看到要求。

## 升级步骤

1. 在个人任务页复制完整升级指令，交给当前选用的 AI 工具；先向学员说明前置任务，再暂停原作业。
2. 核对本人项目、仓库与原任务；保留已暂存、未暂存、未跟踪的工作及连接凭证。
3. 使用原有下载和解包工具，把本站安装包放到临时目录，核对 build-info.json 的文件摘要。首次升级不要求先运行旧工具不存在的命令。
4. 查看已有工具与 Skill 的改动和新旧差异，备份原文件，再处理 scripts/book-collaboration、.agents/skills/book-guild 及本文 docs/collaboration/connection-upgrade-task.md。不能在仓库根目录直接解压覆盖、reset、自动 stash、删未跟踪文件或覆盖业务源码、其他 Skills 和 Hook。个人 Skill 和说明补充应保留；执行文件有自改时先保留并解决差异，不能冒充官方执行版本。
5. 用新版工具重新上号，停止旧心跳，保留本人连接与原任务。执行 `node scripts/book-collaboration/cli.mjs read-upgrade-rules` 并实际阅读输出的新版 Skill、项目 AGENTS.md 和升级说明。此命令不要求已有模板策略、`.codex` 目录或特定厂商的会话输入；没有独立 Read 工具的 Agent 也可以使用。
6. 读完规则并核对原任务后，执行 `complete-upgrade --rules-read`，再用 `upgrade-status` 核对结果。确认命令先心跳、再提交规则读取确认、再发送实际心跳；只在网站返回 COMPLETE 后继续原作业。

网站按当前项目与设备保存结果。A 设备完成不会让 B 自动通过；同一设备改回旧工具、请求缺当前升级声明，也不能复用过去的完成记录。网站任务页按最近使用的本人设备展示，并列出其他设备状态。

如果连接工具文件已受 Git 跟踪，升级会留下工具代码差异。任务0完成只确认本机接入，不代表这些差异已经审核、提交或推送。不要把工具更新混入原作业的修改范围，也不放宽原有干净工作区检查。按已有授权单独登记工程维护变更，明确工具、Skill、实际 Hook 和说明的范围，提交候选并由教师审核后再授权提交；原业务改动保留并分别处理。没有登记或 Git 操作授权时先说明待处理项。原作业最终交付仍须符合原合同与干净工作区要求。

## 状态与边界

- NEEDS_UPGRADE：尚未收到符合要求的工具运行报告。
- VERIFYING：已有新版心跳，规则重读确认或确认后的真实心跳尚未完整。
- COMPLETE：本设备已确认当前要求，随后收到匹配的真实心跳。

执行身份取自稳定的核心文件清单摘要；包时间戳、普通网站部署和学员的 Skill 注释不会改变它。服务端使用构建时生成的同一摘要。部署前必须核对网站要求与实际下载包一致，不能只替换一侧。

规则读取记录按站点、项目、工作区与本人设备凭证隔离，只保存三份规则的路径、状态、文件摘要、实际连接工具版本及读取时间，不缓存或上传规则正文。仅缺失的 AGENTS.md 可明确记录“未设置”；Skill 和升级说明必须实际读取。确认时检查文件仍一致、读取版本匹配且时间在一小时内；已过期或文件变化时重新读取，不伪造记录。完成后的正常开发不会因阅读时间过去或个人规则编辑而反复锁住；模板更新仍走单独的同步和重读流程。

网站核对本人设备、运行版本、读取证据及确认后的匹配心跳，不校验 AI 品牌，不要求专用 Hook。回执是协作流程证据，不能证明 AI 理解了全文或抵抗恶意伪报，也不是任意本地工具的隔离边界。

如果执行文件缺失或损坏，先保存现场，用原有工具在临时目录核对安装包、备份和修复，再重新上号、读取规则并确认。若已有本项目课程 Hook 挡住恢复，由本人在当前工具的管理界面仅暂停这项 Hook，保留其他 Hook；修好后按该工具的方式恢复，暂停期间不继续原作业或自报完成。

选择 Codex 工具操作前额外检查时，可使用可选适配，配置和信任语义见 [Codex 官方 Hooks 文档](https://learn.chatgpt.com/docs/hooks#common-input-fields)。安装、移除或重配此 Hook 都不影响通用升级完成状态，其他 Agent 不需要安装或模拟它。

读取原任务、查看状态、上/下号和升级恢复保持可用。模板来源故障会显式显示状态错误，升级通道仍可处理；模板门禁仍需恢复有效策略后通过。教师审核与独立 CI 不受个人升级任务影响。本功能不发送课程群消息，不批量造业务任务，不改课时发布状态。

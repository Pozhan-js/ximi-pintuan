## 结构与信任边界

Next 页面与同源 BFF 调用 Nest；Next 单独启动仍可访问首页与原型，业务服务未启动时给出重试提示。contracts 提供纯字段校验与北京时间解析。服务端再次校验 unknown 输入并将金额按整数分落库，拒绝客户端身份、状态与额外字段。

Node 原生 SQLite 存放账号、会话、团、规格和图片；迁移及约束随代码交付，无新增依赖。管理员用本机脚本预置账号与团长资格；没有默认密码或输入用户 ID 的身份切换入口。密码使用带盐 scrypt；会话为随机 token，仅数据库存摘要，浏览器 HttpOnly/SameSite cookie；生产要求 HTTPS。登录失败计数限制重试。BFF 拒绝异源写入，Nest 写入要求同源 BFF 请求标记，仍逐次核验会话和归属。

## 状态与并发

草稿允许字段留空，但已填写字段必须有效。创建使用本人范围的 requestId 唯一约束；保存使用 revision 防止覆盖他人/另一窗口改动。预览保存并验证完整草稿，服务端发出绑定版本的 previewToken；确认发布重新验证时间与图片归属，在 SQLite 事务中改变原团状态，不新增发布记录。重试同一发布返回同一结果。发布后拒绝编辑和删除；公开接口只提供已发布商品字段，无后台账号信息。

图片经 multipart 大小限制、MIME 和文件签名校验后持久化；未公开的图片仅本人读取；详情图最多八张。失败保留其余输入。前端展示 A01 列表/筛选、A02 编辑与离开提示、A03 预览和最后确认、A04 只读详情及真实买家入口。

## 范围与限制

仅本机/单持久化服务实例；SQLite 数据目录需备份，不能直接用于无持久卷的 serverless。微信正式登录、订单、支付、结算和物流不在本任务范围，截止后只展示截止事实，不伪造结算结果。数据库配套作业若需额外数据库类型或其他 PRD 表，需另行确认合同；本任务提供真实 SQLite 迁移、约束及查询计划检查。
